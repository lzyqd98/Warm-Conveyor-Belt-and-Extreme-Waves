# Warm-Conveyor-Belt-and-Extreme-Waves
This is the repository for the manuscript "Strengthened Warm Conveyor Belts Amplify Upper-level Rossby Wave Extremes in a Warming Climate"

(1) pv_reconstruction.py is the key code for reconstructing each wave event with/without WCBs.
(2) we_track.py is a code to track upper-level wave event.
