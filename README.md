# Warm-Conveyor-Belt-and-Extreme-Waves
This repository contains relevant codes for the manuscript "Strengthened Warm Conveyor Belts Amplify Upper-level Rossby Wave Extremes in a Warming Climate"

(1) pv_reconstruction.py: key code for reconstructing each wave event with/without WCBs.
(2) we_track.py: code to track upper-level wave event.
